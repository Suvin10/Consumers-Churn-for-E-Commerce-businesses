# 🛍️ E-Commerce Customer Churn Prediction using Machine Learning

## 📌 Overview
This project presents a comprehensive exploration of machine learning methodologies applied to the **e-commerce domain**, focusing on analyzing variables influencing **customer churn**—a key business concern. The study applies end-to-end data science techniques including **data collection**, **EDA**, **data preprocessing**, **model building**, **evaluation**, and **business strategy recommendations** to help reduce churn and improve retention.

---

## 🔍 Project Objectives
- Identify key variables influencing customer churn in an e-commerce dataset.
- Develop and evaluate various machine learning models for churn prediction.
- Recommend actionable business strategies based on the insights and model results.

---

## 🧠 Machine Learning Techniques Used
- **Data Preprocessing**:  
  - Handling missing values  
  - Outlier treatment  
  - Correlation analysis  
  - Balancing imbalanced datasets  
  - Feature scaling and normalization  

- **Models Implemented**:  
  - Decision Tree  
  - Logistic Regression  
  - K-Nearest Neighbors (KNN)  
  - Random Forest  
  - Support Vector Machine (SVM)  
  - XGBoost Classifier  
  - AdaBoost Classifier  
  - Artificial Neural Network (ANN)

- **Evaluation Metrics**:  
  - Accuracy  
  - F1 Score  
  - AUC-ROC  
  - Precision  
  - Recall

- **Model Tuning**:  
  - Hyperparameter tuning to improve model performance  

---

## 🏆 Best Performing Models
After thorough evaluation and tuning:
- **XGBoost** and **Support Vector Machine (SVM)** achieved the highest scores across key metrics.
- **Random Forest** also performed strongly and was considered among the top models.

---

## 💡 Key Business Insights & Recommendations
Based on variable analysis and model outcomes, the following strategies are proposed to reduce churn:

1. **Male Engagement**: Targeted campaigns for male customers.
2. **Product Diversification**: Broaden offerings to suit diverse marital statuses.
3. **Mobile App Optimization**: Enhance mobile experience to increase retention.
4. **City-Tailored Marketing**: Customize strategies by city tier.
5. **Coupon Utilization**: Increase loyalty through smart coupon promotions.
6. **Customer Complaint Resolution**: Address issues promptly to boost satisfaction.
7. **Warehouse Strategy**: Improve service by optimizing warehouse locations.
8. **Payment Method Optimization**: Customize payment options based on region.
9. **Promotion for Order Count**: Encourage repeat orders to reduce churn.
10. **Cashback Strategy**: Balance attractive cashback offers with retention goals.

---

## 📈 Results Summary
- Highest model accuracy achieved: **96.66%**
- Best F1 score: **96.76%** (Random Forest)
- After tuning, **XGBoost** and **SVM** demonstrated nearly identical, top-tier performance.
